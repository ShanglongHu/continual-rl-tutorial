# 心理与神经科学等视角：学习、心智与意识

智能、心智、认知与意识不是同一个问题。心理学研究行为与经验的规律；神经科学研究其生物机制；控制论与经济学研究反馈、决策和资源限制；哲学追问表征、理解与主观体验的含义。本篇从各学科自身的问题出发，介绍重要实验、理论、论证与争议。与强化学习的联系是一条可选的思考路径，而不是预先规定的答案。

这是技术教材之外的补充阅读，不是学习算法的前置要求。

## 经验怎样改变行为与知识

从学习信号到记忆与情境，理解行为改善可能发生在哪个过程。

- [预测误差与学习信号：从条件作用到突触可塑性](../textbook/supplements/signals.md)：一次意外发生后，学习系统怎样判断该学什么，以及哪些过去的活动应当发生改变？
- [目标、习惯与身体需要：结果为什么值得追求？](../textbook/supplements/motivation.md)：行为改变了，究竟是结果不再有价值、动作不再有效，还是已有知识没有被用于当前选择？
- [记忆系统：保持、调用与更新](../textbook/supplements/memory.md)：旧经验没有出现在当前行为中，是没有保存、无法调用，还是暂时不该使用？
- [情境与结构：经验如何成为可迁移的状态](../textbook/supplements/context.md)：眼前景象相同，正确行动为何不同？新任务改变了对象，却保留了关系时，哪些知识可以复用？
- [学习机制与功能组织：经验如何改变未来的适应](../textbook/supplements/organization.md)：智能体不仅学会一个动作，还可能学会怎样更快地学习。快速活动变化、缓慢可塑性与功能分工之间有什么关系？

## 怎样阅读跨学科解释

- 观察到的现象：在什么物种、任务和测量下出现？ 行为或神经活动的相关性，本身不唯一确定机制。
- 计算解释：给定什么假设，模型为什么产生这个现象？ 能拟合现象，不等于证明系统采用同一个算法。
- 可区分的预测：哪种新条件会让竞争解释得出不同结果？ 对一个部件的干预，可能同时改变感觉、动机或动作执行。
- 对人工学习的启发：保留什么机制，在什么条件下可能有用？ 提高人工任务收益与解释生物机制，是两项需要分别验证的主张。

## 阅读起点

[Sutton 与 Barto，《Reinforcement Learning: An Introduction》第二版](https://mitpress.ublish.com/book/reinforcement-learning-an-introduction-2)的第三部分将强化学习与心理学、神经科学及应用相联系。本补充篇沿这种问题导向的方式继续讨论，并扩展到控制论、经济学、意识理论与心灵哲学。各学科有自己的解释目标，不要求将每个概念对应为智能体模块。思想实验检验论证的前提与一致性，不代替关于真实系统的经验测量。
