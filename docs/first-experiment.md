# 第一个完整实验：从一条更新式，到一页结论

[学习首页](../README.md) · [第 2 课的推导](../tutorials/02-tracking.md)

约 60–90 分钟。只需要动作、奖励、样本平均和运行 Python 的基础；不需要 GPU。

## 1. 先预测现象

每步在 A、B 中选一个，得到 0 或 1 的奖励。前 2,000 步，奖励为 1 的概率分别为 0.8、0.2；
从第 2,001 步开始交换。学习器不知道切换时刻，只看到自己动作的奖励；价值与计数不清零。

两种方法使用同一种 ε-greedy 规则，区别只有新证据的权重：

- 样本平均：第 N 次选择动作 a，步长用 1/N。
- 常数步长：每次都用 α。

运行前写下预测：谁恢复更快？谁的估值更平滑？不一定是同一个答案。

## 2. 手算与读码

更新只有三步：选动作、观察奖励、修正该动作的估值。

```python
n[action] += 1
rate = 1 / n[action] if method == 'sample_mean' else alpha
q[action] += rate * (reward - q[action])
```

α=0.1、Q(A)=0.8、R=0 时，Q(A) 变为 0.72。未选择的动作不更新。
第二课说明这为何让旧奖励的影响指数衰减。

打开 [bandit()](../examples/crl_labs.py)，依次找到：

| 变量 / 部分 | 角色 |
|---|---|
| action | ε-greedy 决策；平局随机打破 |
| probs | 环境在全局时刻切换的奖励概率 |
| rate | 唯一要比较的学习规则 |
| metrics | 奖励、选择 B 的比例、Q(A)、Q(B) |

切换条件只在环境一侧。切换时清空 Q 会改变实验权限。

## 3. 运行并生成报告

以下命令从仓库根目录运行，输出文件使用新名字：

```sh
python3 examples/crl_labs.py bandit --seeds 20 --steps 4000 --alpha 0.1 --epsilon 0.1 --out bandit-a01.csv
python3 examples/analyze_crl.py bandit-a01.csv --out bandit-a01.html
```

打开 `bandit-a01.html`。无需绘图库，也无需启动服务器。

完成检查：CSV 应有 **6,400 行数据和 1 行表头**；
两个方法 × 20 seeds × 40 个窗口 × 4 项指标。
报告有 4 张图和分段奖励表。随机种子为 0 到 19。

## 4. 按“结果 → 行为 → 估计”看图

| 图 | 能回答什么 | 不能单独回答什么 |
|---|---|---|
| 窗口奖励 | 收益怎样下降和恢复 | 为什么恢复慢 |
| 选择 B 的比例 | 是否逐渐放弃旧的好动作 | Q 值为什么变 |
| Q(A)、Q(B) | 估值排序和波动怎样影响行为 | 深度网络有没有失去可塑性 |

粗线是均值，浅线是每个 seed。分段奖励按实际窗口长度加权；
“±”是 seed 间样本标准差，不是置信区间。

**思考**：即使 B 的估值始终更高，为什么选择 B 也通常不是 100%？

<details>
<summary>参考答案</summary>

ε=0.1 时，10% 的步数随机选择两个动作，所以约 5% 仍选 A。
有限样本和估值波动会进一步影响比例。

</details>

## 5. 只改一个因素

保持 steps、seeds、ε 相同，只将 α 改成 0.5：

```sh
python3 examples/crl_labs.py bandit --seeds 20 --steps 4000 --alpha 0.5 --epsilon 0.1 --out bandit-a05.csv
python3 examples/analyze_crl.py bandit-a05.csv --out bandit-a05.html
```

样本平均结果应逐点相同，因为它不用 α；常数步长的恢复与波动可能变化。
若不满足这个不变性，先排查实验配置，而不是解释曲线。

扩展练习：

1. 令 ε=0，区分缺少随机探索和更新慢。奖励噪声、平局仍可能导致动作切换。
2. 令 `--switch 3000`，但要报告变化后只剩 1,000 步。
3. 先选定配置，再增加独立 seeds；不要只挑好看的运行。

## 6. 写第一张结论卡

```text
问题：奖励反转后，哪种估计规则更容易适应？
协议：4,000 步；2,000 步后反转；无通知、无清零；ε=0.1。
只改一项：常数步长 α=0.1 → 0.5。
观察：填写变化后起始段与剩余段的均值、SD；解释动作和 Q 值。
其他解释：探索不足？估值噪声？少数 seed 主导？
结论边界：这是两臂奖励跟踪，不代表深度可塑性或所有 CRL。
下一步：只增加一个能排除其他解释的对照。
```

## 卡住时检查什么

- 找不到脚本：先进入仓库根目录；确认文件不是 `.py.txt`。
- 输出已存在：换新文件名，不覆盖原结果。
- 报告拒绝 CSV：使用本仓库配套 bandit 输出，其他实验不共用该报告器。
- 与预测不同：保存结果，检查配置和全部 seeds，不要修改曲线去符合预期。
