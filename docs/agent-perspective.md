# 从三元间接交互到二元直接交互

**三元：先把世界任务化**

设计者构造实验环境，规定观测、动作、奖励、时限、重置与任务安排。

大世界 → 外部设计者的选择、简化、封装 → 实验环境 ↔ 智能体。

在给定接口中学习预测与控制

**二元：同一个行动者承受后果**

有限智能体在持续经验中形成状态、预测、控制、子任务与技能、模型与规划、学习调节。

大世界 ↔ 有限智能体。

在经验中形成、使用、校准与替换

两边的执行都包含智能体—环境交互。区别在于哪些工作被设计者提前完成，哪些仍要由行动者从经验中学习承担。右侧不意味着没有设计者，也不意味着可以自行改写最终奖励。

强化学习研究智能体如何通过与环境交互学习，以实现目标。在三元结构中，设计者先把世界组织成任务，智能体在给定条件下学习。二元方向进一步追问：如果不再由设计者逐项提供状态、子任务和技能，同一个智能体怎样从长期经验中形成这些能力？这条从“给定”到“学得”的主线，贯穿后面的状态、预测、控制、时间抽象与规划。

## 从三元间接交互到二元直接交互：哪些工作由谁完成？

先看左图。设计者从大世界中选出一类问题，把它做成可运行的实验环境：规定智能体看到什么、能做什么、怎样获得奖励、何时结束，以及失败后怎样重来。智能体在这些条件下学习预测与控制。这里的“三元”指智能体、外部设计者和大世界；图中的实验环境，是设计者选择和组织问题的结果。

$$
W\xrightarrow{\ D\ }\mathcal E_D\longleftrightarrow\mathsf{Ag}\qquad\longrightarrow\qquad W\longleftrightarrow\mathsf{Ag}.
$$

$W$ 表示大世界，$D$ 表示设计者的选择与任务化过程，$\mathcal E_D$ 是构造出的实验环境，$\mathsf{Ag}$ 是智能体。中间箭头表示研究方向：把更多原先由设计者完成的工作，转为智能体需要从经验中学习的工作。

再看右图。研究对象转为同一个智能体在大世界中的长期交互。哪些历史值得记住、哪些后果值得预测、需要什么技能、何时使用模型，这些问题不能都等着设计者逐项给出答案。智能体需要从自己的经验中形成和修订这些能力，并面对此前行动留下的后果。

从智能体的视角理解这一步，关键是区分“世界中有什么”和“我实际知道什么”。设计者可能知道完整的模拟器状态，但智能体只收到观测和奖励。若接口直接给出速度或任务标签，这些信息就是外部提供的；若需要根据历史判断运动趋势或识别任务变化，这部分工作才需要由智能体完成。不能把设计者提供的知识，算作智能体从经验学到的知识。

这也解释了为什么不能只按程序文件或神经网络的边缘划定智能体。把同一个历史缓存从环境代码移到智能体代码，若保留相同的信号、时序和资源条件，只是换了边界画法。以四帧堆叠为例：智能体若原本就能保存逐帧历史，外部堆叠是在替它做缓存，不是凭空增加历史信息。真正需要比较的是哪些信息能够获得、哪些计算由外部完成，以及哪些能力需要学习。

二元交互仍然需要传感器、行动器、奖励来源、初始学习规则、资源和安全约束。它减少的是运行时不断替智能体指定任务、提供现成知识或恢复世界的专门帮助。自主形成内部目标，也不等于可以任意改写最终奖励。

经典强化学习的执行接口本来就是智能体—环境。这里的三元／二元不是用三方通信替代两方通信，而是在原有交互之上追问：设计者已经解决了哪些问题，剩下哪些问题真正交给了学习器？下面把这些工作逐项展开。

### 从给定条件到学习问题

**提供充分状态 → 从有限历史构造可修订的状态**

混叠的历史可能要求不同动作；增加网络宽度不能恢复已丢掉的信息。

[对应教材与实验](../textbook/state.md)

**指定全部预测目标 → 提出并校准有用途的 GVF 问题**

预测误差下降不保证控制改善；目标策略覆盖不足时，答案也可能不可识别。

[对应教材与实验](../textbook/gvf.md)

**指定子任务与技能库 → 构建子问题、内部策略与终止规则**

到达子目标可能损害主奖励；技能策略改变后，其模型也必须重新校准。

[对应教材与实验](../textbook/options.md)

**提供可查询的精确模型 → 学习行动后果并分配规划计算**

搜索会使用训练数据没有覆盖的状态；低一步误差不保证多步决策正确。

[对应教材与实验](../textbook/planning.md)

**提供重置、阶段与人工恢复 → 在当前世界状态上探索、适应和恢复**

早期行动可能永久改变以后可达的状态。只报告最终控制器的分数，会遗漏此前的学习与恢复成本。

[对应教材与实验](../textbook/control.md)

**用多条完整开发寿命离线选参 → 依据当前与过去反馈调节学习**

两者都不得窥看测试未来。调节步长、信用尺度与结构的规则也要承担信息、计算和干扰成本。

## 从持续交互中，辨认相互关联的学习问题

沿着右图往下看：当前观测可能不够，需要记忆；不知道行动后果，需要预测；必须选择行动，需要控制；不能每次都从头推算，需要可复用的技能和模型。这些工作还要在有限时间、记忆和计算中完成。下表说明每个困难怎样引出一个学习问题。

| 不可省略的事实 | 因此需要研究什么 | 如何检验，而不只看训练 loss |
| --- | --- | --- |
| 当前观测未必区分后果不同的历史。 | 状态构建与记忆。 | 控制当前观测，改变早期线索；检查后续预测和动作是否仍可区分。 |
| 动作同时选择收益、状态与未来信息。 | 预测、探索与控制。 | 把信息成本计入完整收益；比较当时信息相同的可行学习器。 |
| 未来跨越多个时间尺度，计算有限。 | GVF、option model 与规划。 | 固定真实步数，再分别记录模型误差、模型调用与实际行为效果。 |
| 同一参数服务多个问题，旧知识会失效。 | 信用分配、可塑性与知识维护。 | 同时测旧规律回访和新规律习得；观察局部更新对其他模块的影响。 |
| 可学习的对象远多于可保存的对象。 | 内部问题构建和资源分配。 | 计入候选生成、学习与保留成本；确认被保留对象有实际使用者。 |

这些是相互约束的学习问题，不是必须依次训练完的流水线。状态为预测与控制提供坐标；预测误差反过来检验状态。控制改变后续样本；技能改变模型要预测的行为。元学习调节更新规则，但它同样受可用信息和计算限制。

还要看这些能力怎样随经验改变。两个系统当前表现相同，遇到新情况后可能学得快慢不同。因而，最终控制器的成绩不能代替整个学习过程的评价；此前的探索损失、恢复成本和后来的适应，都需要计入。

同样，计算不能脱离交互时间。模拟器可以等待算法规划完再运行，真实世界未必等待。增加搜索可能改善动作，也可能增加延迟；要把两方面放在一起比较。

GVF、option 和显式规划是解决这些问题的候选工具，不是从有限资源这一事实必然推出的模块。本文沿 Alberta Plan 组织它们；其他架构可以采用不同的分解，也需要说明怎样处理相同的信息、时间和计算困难。

大世界假设选择的是“世界的相关复杂性超过智能体资源”的问题类。它不意味着世界必须无限，也不由此证明任意有限任务都必须永远学习。需要另外说明容量、经验结构和目标，才能分析何种持续适应有益。

## 阅读与研究练习

<a id="agent-perspective-question-information"></a>

- 分别列出环境内部状态、接口观测与智能体保存的摘要。哪些区别会影响未来行动，却没有进入当前摘要？

<a id="agent-perspective-question-boundary"></a>

- 把帧堆叠移入智能体，与取消外部任务标签或重置，有何不同？逐项说明信息、存储、恢复职责和计算成本是否改变。

<a id="agent-perspective-question-consequences"></a>

- 当前策略很少访问某类状态时，已有数据上的预测准确是否足以支持可靠控制？还需要哪些经验？

<a id="agent-perspective-question-learning"></a>

- 固定网络权重而保留记忆更新，究竟停止了什么？怎样通过禁写、擦除或置换记忆检验经验对后续表现的贡献？

<a id="question-learner-evaluation"></a>

- 完整学习器和最终控制器分别按什么准则评价？此前的探索、恢复和计算成本是否进入比较？

<a id="question-mechanism-evidence"></a>

- 推导的条件是否与实验一致？哪一项可观测结果会推翻关于机制作用的解释？

- [温颖 · 从现代深度强化学习到持续强化学习](https://yingwen.io/zh/blog/from-modern-deep-rl-to-continual-rl/)：本书总览的研究主线：设计者职责、第一人称经验与内部学习对象的形成。
- [Anna Harutyunyan · What is an agent?（2020）](https://anna.harutyunyan.net/wp-content/uploads/2020/09/What_is_an_agent.pdf)：策略与完整学习过程、智能体—环境边界的概念讨论；不提供任意架构的性能保证。
- [Nan Jiang · On Value Functions and the Agent-Environment Boundary（2019；2020 修订）](https://arxiv.org/abs/1905.13341)：批量 FQI 的边界不变分析，依赖数据覆盖和函数类条件；不等于任意改变信息接口后算法均不变。
- [Orseau、Ring · Space-Time Embedded Intelligence（2012）](https://www.cs.utexas.edu/~ring/Orseau%2C%20Ring%3B%20Space-Time%20Embedded%20Intelligence%2C%20AGI%202012.pdf)：计算、记忆和程序处于世界中的理论建模视角。
- [Sutton、Bowling、Pilarski · The Alberta Plan for AI Research](https://arxiv.org/abs/2208.11173)：普通经验、时间统一、计算限制与从组成部分到完整智能体的研究路线。
